# User Registry With Rewards

Educational Solidity smart contract demonstrating decentralized user registration and reward distribution on Ethereum.

## Features

- User registration
- On-chain reward distribution
- Ownership access control
- Event emission
- Gas-related concepts
- EVM execution model explanation

## Technologies

- Solidity ^0.8.20
- Ethereum Virtual Machine (EVM)

## Smart Contract

```solidity
contract UserRegistryWithRewards
```

## Concepts Demonstrated

- mappings
- structs
- modifiers
- events
- storage operations
- gas consumption
- decentralized state management

## Possible Use Cases

- Web3 onboarding
- DAO communities
- Educational dApps
- Reward systems
- Loyalty platforms

## Purpose

This project was developed as an educational exercise to study Solidity fundamentals, EVM behavior, and decentralized application architecture.
